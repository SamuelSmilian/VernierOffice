# VernierOffice

**VernierOffice** is an experimental document language and compiler designed for AI-assisted document generation.

Instead of manipulating Office documents through complex APIs, VernierOffice provides a lightweight semantic language that can be compiled into multiple formats.

The project currently focuses on:

- A minimal semantic document model
- A lightweight LaTeX-inspired syntax
- DOCX as the first compilation target
